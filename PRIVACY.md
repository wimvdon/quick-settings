# Privacy policy

_Last updated: 2026-11-09_

**This app collects nothing.**

- It does not collect, store, or share any personal data.
- It has no internet access, no analytics, no advertising and no crash reporting.
- It stores no data of its own. It only reads and changes four of Android's screen settings
  (brightness, screen timeout, always-on display, tap to wake) when you ask it to.
- Permissions, all used only for that:
  - **Modify system settings**: to change brightness and screen timeout.
  - **Write secure settings** (granted only with an adb command you run yourself): to change
    always-on display and tap to wake.
  - **Notifications**: to show that brightness is manual or the timeout is extended, with a
    button to put it back.

If this changes, this file will be updated **before** the change is released, describing what is
collected, why, where it is stored, and how to delete it.

Questions: open an issue in this repository.
